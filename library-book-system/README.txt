Question Q14 PHP + MySQL Execution

1. Copy this Q14 folder into C:\xampp\htdocs\
2. Start Apache and MySQL in XAMPP.
3. Open http://localhost/phpmyadmin
4. Import database.sql from this folder.
5. Run http://localhost/Q14/index.php

Main files:
- index.php: main page
- config.php: database connection
- database.sql: SQL commands to create database and table
- style.css: page styling
- script.js: small browser-side logic/comments
