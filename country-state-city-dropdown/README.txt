Q23 Country-State-City Dropdown

Files:
1. index.html
2. style.css
3. script.js
4. data.json

How to run correctly:
Best method:
1. Copy Q23 folder to C:\xampp\htdocs\
2. Start Apache in XAMPP.
3. Open this URL:
   http://localhost/Q23/index.html

Alternative:
Use VS Code Live Server and open index.html.

Note:
This practical uses XMLHttpRequest to load data.json using AJAX.
If you double-click index.html directly, some browsers block AJAX from local files.
So backup data is also added inside script.js to keep the dropdown working.
